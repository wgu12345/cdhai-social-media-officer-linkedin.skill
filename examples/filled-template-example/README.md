# Filled Template Example

This folder shows what a user's working folder looks like, fully prepared
to run the skill. To use as a reference:

1. Open `content.docx` to see how Purpose / Post Type / Date / Key Points
   are filled in.
2. The skill reads everything in this folder — `content.docx`, the
   PDF agenda, and the images.

Drop your own version of `content.docx` into a fresh folder of your own
work materials, and run the skill.
